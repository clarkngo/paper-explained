# Paper Explained

Concise, leveled breakdowns of academic papers for developers — what each paper changed, why it matters, and how to reason about the idea at different experience levels (ELI5 through senior-dev depth).

## Usage

This is a static site with no build step. Open [index.html](index.html) in a browser, or serve the directory locally, e.g.:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`. Source PDFs for the covered papers live in [papers/](papers/).
